# Chamomile Emacs 配置

`early-init.el` 负责首帧设置、包激活缓存和启动期 GC；`init.el` 只指定模块的加载顺序。自定义函数和变量统一使用 `chamomile/` 前缀。

| 模块 | 职责 |
| --- | --- |
| [`init-packages.el`](lisp/init-packages.el) | 软件源、包安装、独立的 `custom.el` |
| [`init-ui.el`](lisp/init-ui.el) | 主题、GUI 字体、相对行号和滚动 |
| [`init-editor.el`](lisp/init-editor.el) | 编辑行为、多光标、行尾空白和快捷命令 |
| [`init-navigation.el`](lisp/init-navigation.el) | Ido / Smex、窗口管理、Dired、搜索、Git 和头文件跳转 |
| [`init-languages.el`](lisp/init-languages.el) | 编程主模式、缩进和编译 |
| [`init-lsp.el`](lisp/init-lsp.el) | Eglot 自动连接和 Corfu 自动补全 |
| [`init-org.el`](lisp/init-org.el) | Org 议程、捕获、计时和剪贴板链接 |

模块文件在启动时主要登记快捷键、后缀和 hook。主题和 Ido 立即启用；Winner 从启动就记录窗口布局。Magit、Smex、Windmove、语言主模式和 Org 工具在实际用到时才加载。议程目录仅在加载 Agenda 或 Capture 时创建。

首次启用包激活缓存时，可执行 `M-x package-quickstart-refresh`。`M-x emacs-init-time` 可查看启动耗时。

## 快捷键速查

`C-` 表示 Ctrl，`M-` 通常表示 Alt，`S-` 表示 Shift，`RET` 表示回车。空格分隔的是依次按下的组合，例如 `C-x C-f` 是先按 Ctrl+x，再按 Ctrl+f。`M-X` 的 `X` 是大写，需要按住 Shift。

### 编辑与多光标

| 快捷键 | 功能 |
| --- | --- |
| `C-,` | 复制当前行，光标留在新行的相同位置 |
| `C-c w` | 清除行尾空白（有选区时只清除选区内的空白） |
| `C-S-c C-S-c` | 先选中多行，再为选区内的每一行添加一个光标 |
| `C->` / `C-<` | 先选中一段文字，再向后／向前添加一个匹配的光标 |
| `C-c C-<` | 为缓冲区内所有与选区匹配的位置添加光标 |
| `C-c C-s` | 跳过最后一个向后选中的匹配，改选下一个 |
| `C-c C-d` | 移除最后一个向后添加的匹配光标 |
| `C-c C-j` | 在 Emacs Lisp 缓冲区中，求值光标前的表达式并把结果插入缓冲区 |
| `C-x C-c` | 退出 Emacs；有未保存的修改时，在底部文字提示中按 `y` 保存、`n` 跳过、`!` 保存剩余文件、`C-g` 取消退出。跳过的修改会在退出前再次确认 |

### 文件、缓冲区与搜索

| 快捷键 | 功能 |
| --- | --- |
| `C-x C-f` / `C-x b` | 用 Ido 打开文件／切换缓冲区 |
| `C-n` / `C-p` | 在 Ido 的纵向候选列表中选择下一项／上一项 |
| `M-x` / `M-X` | 用 Smex 搜索所有命令／当前主模式的命令 |
| `C-x C-g` | 在另一个窗口打开光标处的文件；在 `#include` 行上会查找 C/C++ 头文件 |
| `C-c s` | 从当前目录递归搜索选中的文字；没有选区时提示输入搜索条件 |
| `C-c i m` | 用 Imenu 跳转到当前缓冲区内的函数、类型或其他条目，列表由主模式提供 |

### 窗口与 Git

| 快捷键 | 功能 |
| --- | --- |
| `Shift + 方向键` | 切换到该方向的窗口 |
| `C-c <left>` / `C-c <right>` | 用 Winner 撤销／重做窗口布局，不影响文件内容 |
| `C-x g` | 打开当前 Git 仓库的 Magit 状态页面 |

Git 已跟踪的本地文本文件会在行号旁标出改动，并在状态栏显示 `+新增行数 -删除行数`。统计的是已保存内容相对 `HEAD` 的差异，包含已暂存和未暂存的改动，不包含尚未保存的编辑。打开、保存、重载文件或刷新 Magit 时会更新；没有差异时隐藏统计。

### Dired 与 WDired

这里使用 Emacs 内置的 Dired 和 WDired，无需额外插件。除特别标注外，下面都是内置键位；`C-c C-e` 是本配置额外绑定的入口。单字母键区分大小写，例如 `d` 与 `D` 的删除流程不同。

#### 打开与导航

| 快捷键 | 功能 |
| --- | --- |
| `C-x d` / `C-x 4 d` | 输入目录，在当前窗口／另一个窗口打开 Dired |
| `C-x C-j` / `C-x 4 C-j` | 在当前窗口／另一个窗口打开当前文件的目录，并定位到该文件；已经在 Dired 中时则跳到上一级并定位到原目录 |
| `RET` / `f` / `e` | 打开光标处的文件，或进入该目录 |
| `o` / `C-o` | 在另一个窗口打开当前条目；`o` 切换焦点，`C-o` 保留 Dired 焦点 |
| `v` | 以只读查看模式打开当前文件 |
| `n` / `p`（也可用 `↓` / `↑` 或 `C-n` / `C-p`） | 移到下一条／上一条 |
| `^` | 打开上一级目录 |
| `j` | 输入路径，定位到列表中的对应条目 |
| `q` | 退出当前 Dired 窗口，不删除文件 |

#### 列表显示与搜索

| 快捷键 | 功能 |
| --- | --- |
| `(` | 切换权限、大小、时间等详情的显示；本配置默认隐藏详情 |
| `g` / `l` | 刷新整个列表／刷新选中文件（未标记时刷新当前文件）的条目 |
| `s` / `C-u s` | 切换文件名排序和时间排序／手动编辑当前目录的 `ls` 参数 |
| `i` / `$` / `M-$` | 将当前子目录内容插入同一缓冲区／折叠或展开当前子目录／切换所有子目录的显示 |
| `k` | 从列表中移除对应的行，不删除磁盘上的文件；按 `g` 恢复 |
| `M-s f C-s` / `M-s f C-M-s` | 按文件名增量搜索／按正则表达式搜索文件名 |
| `M-s a C-s` / `M-s a C-M-s` | 在已标记文件的内容中增量搜索／按正则表达式搜索 |
| `?` / `C-h b` | 查看 Dired 简要提示／查看当前缓冲区完整的有效键位，包括扩展命令 |

#### 标记与批量操作

| 快捷键 | 功能 |
| --- | --- |
| `m` / `u` | 标记／取消标记当前条目，然后移到下一行 |
| `DEL` | 向上一行移动并取消该行标记；`DEL` 通常是 Backspace |
| `U` / `t` | 清除所有标记和待删除标记／反选普通标记 |
| `% m` / `% g` | 按文件名正则标记／标记内容匹配正则的文件 |
| `* /` / `* @` / `* *` | 分别标记目录／符号链接／可执行文件 |
| `M-{` / `M-}` | 跳到上一个／下一个标记条目 |
| `+` | 创建目录 |
| `C` / `R` | 复制／重命名或移动选中的文件 |
| `d` / `x` | `d` 只标记待删除，不立即删除；`x` 执行所有待删除标记并要求确认 |
| `% d` / `D` | 按文件名正则标记待删除／直接进入删除已标记文件（无普通标记时为当前文件）的确认流程 |
| `w` / `C-0 w` | 把文件名／绝对路径复制到 kill ring，可用 `C-y` 粘贴 |
| `S` / `Y` / `H` | 创建符号链接／相对路径符号链接／硬链接 |
| `M` / `T` | 修改权限／修改时间戳 |
| `=` / `y` | 将当前文件与另一文件做 diff／查看当前文件类型 |
| `Z` / `c` | 压缩或解压选中文件／把选中文件打包到指定归档文件 |
| `E` | 用系统默认的外部程序打开选中的文件 |
| `!` / `&` | 对选中的文件执行同步／异步 shell 命令 |

`C`、`R`、`D` 等文件操作通常优先处理普通标记（`m`），没有标记时处理光标处的文件。要在目录间复制或移动，先用 `C-x 4 d` 打开目标目录，再在源目录按 `C` 或 `R`；本配置会把另一个 Dired 窗口的目录作为默认目标。删除目录时，当前配置会对顶层目录确认，确认后递归删除其中内容，不逐个询问。

#### WDired：像编辑文本一样修改文件名

| 快捷键 | 功能 |
| --- | --- |
| `C-c C-e` / `C-x C-q` | 在普通 Dired 中进入 WDired，可直接编辑多个文件名 |
| `C-p` / `C-n`（或 `↑` / `↓`） | 移到上一行／下一行文件名 |
| `C-c C-c` / `C-x C-s` | 提交实际的重命名操作，并返回 Dired |
| `C-c C-k` / `C-c C-[` | 放弃本次编辑，不改磁盘上的文件名，并返回 Dired |
| `C-x C-q` | 从 WDired 退出；如有未提交的修改，会询问是否保存 |

批量重命名示例：在 Dired 按 `C-c C-e`，编辑列表中的文件名，检查无误后按 `C-c C-c`；反悔就按 `C-c C-k`。

### 编译与代码跳转

| 快捷键 | 功能 |
| --- | --- |
| `F5` / `F6` | 提示编译命令（按语言和构建文件预填）／重新运行当前缓冲区的编译命令 |
| `M-.` / `M-,` | 跳转到定义／返回跳转前的位置；Eglot 接管时由语言服务器提供定义位置 |
| `↑` / `↓`（或 `M-p` / `M-n`） | Corfu 弹窗显示时选择上一项／下一项 |
| `RET` / `C-g` | 确认 Corfu 候选／关闭弹窗 |

`F5` 从当前文件所在目录向上查找构建文件，在找到的目录执行命令。也可以直接编辑预填命令，例如把 `cargo build` 改为 `cargo test`；同一缓冲区会记住修改。项目也可通过 `.dir-locals.el` 指定 `compile-command`。

| 文件类型 | 项目默认命令 | 没有构建文件时 |
| --- | --- | --- |
| Rust | `cargo build`（`Cargo.toml`） | 用 `rustc` 检查当前文件，不保留生成物 |
| Zig | `zig build`（`build.zig`） | 用 `zig build-exe -fno-emit-bin` 检查当前文件 |
| Go | `go build ./...`（`go.mod`） | 构建当前文件，不保留生成物 |
| C / C++ | `make` 或 `cmake --build build`（项目的构建文件） | 用 `cc` / `c++` 检查当前文件，不生成可执行文件 |

如果 CMake 项目尚未配置，先在项目目录运行 `cmake -S . -B build`。其他语言仍使用 Emacs 默认的编译提示。

### Org 议程、任务与链接

| 快捷键 | 功能 |
| --- | --- |
| `C-x a` | 打开议程菜单：`u` 看未安排时间且无截止日期的个人待办，`p` 看个人议程，`w` 看工作议程 |
| `C-c c` | 打开捕获菜单：`p` 记录普通任务，大写 `K` 从剪贴板 URL 生成链接任务；都写入 `~/Documents/Agenda/Tasks.org` |
| `C-c C-x j` | 跳转到当前正在计时的 Org 任务 |
| `C-x p i` | 抓取剪贴板 URL 的网页标题，并插入 Org 链接 |
| `C-x p t` | 在当前位置从剪贴板 URL 插入一个带链接的 TODO |
| `C-x p w` | 复制当前 Org 标题的纯文本，不含 TODO 状态和标签 |

## LSP 和自动补全

打开本地源码时，只有相应服务器在 Emacs 的 `exec-path` 中才会自动连接：`clangd`（C/C++）、`rust-analyzer`（Rust）、`zls`（Zig）、`typescript-language-server`（JS/TS/TSX）、`lua-language-server`（Lua）和 `bash-language-server`（Bash/sh）。使用 rustup 时，Rust 项目选用的工具链需要安装 `rust-analyzer` 组件。

Eglot 接管后，输入两个字符并短暂停顿，或输入 `.` 时，有候选就会在光标旁弹出 Corfu。不需要按补全快捷键。

Flymake 会在行尾显示最严重的一条诊断（仅显示，不修改源码）。用 `M-x flymake-show-buffer-diagnostics` 查看当前文件的完整诊断列表。
